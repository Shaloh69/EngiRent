# Extra deps for running the kiosk software on a Windows/PC dev machine
# (Start-Dev.bat, MOCK_GPIO=True MOCK_CAMERA=True) instead of the real Pi.
#
# requirements.txt deliberately does NOT include opencv/numpy — the Pi gets
# them from apt (python3-opencv) to avoid conflicting with the system
# package (see requirements.txt's own comment). A dev PC has no such system
# package, so they're installed here instead. lgpio is still never needed
# off-Pi — hardware/gpio_controller.py and actuator_controller.py only
# import it when MOCK_GPIO=False.
#
# Usage (from server/kiosk/):
#   python -m venv venv
#   venv\Scripts\pip install -r requirements.txt -r requirements-dev.txt
-r requirements.txt
